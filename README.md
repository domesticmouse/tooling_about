# tooling_about

A desktop Flutter client demonstrating Google **Antigravity** agent orchestration paired with **Generative UI** (`genui`) dynamic surfaces and real-time subprocess tracing.

---

## Features

- **Google Antigravity Agent Orchestration**: Connects to the Antigravity runtime with support for Google Gemini models (`gemini-3.8-flash`, `gemini-2.5-pro`, `gemini-2.5-flash`), custom system instructions, and real-time streaming responses.
- **Dynamic Generative UI (GenUI / A2UI)**: Renders interactive components in-stream generated by the agent, automatically dispatching user action events back to the session:
  - `MultipleChoiceQuestion`: Interactive single or multi-choice questionnaire card with an automatic "Other (write your own answer)" free-text field and real-time validation.
  - `ConfirmationCard`: Action/tool approval card for sensitive or destructive operations (e.g., executing commands, deployments, file deletions), featuring customizable button labels, optional details box, and destructive state styling.
  - `FeedbackRatingCard`: Star rating card (1–5 stars or custom scale) with optional written comments, interactive hover tooltips, and completion status badge.
- **Subprocess Trace Drawer**: Slide-out panel providing real-time visibility into all inbound (`<<<`), outbound (`>>>`), system, and error events with search filtering, directional filters, auto-scroll with queued-flow physics, and syntax-highlighted YAML formatting (`yaml_highlighter.dart`).
- **Collapsible Reasoning**: Live streaming and markdown formatting of model thought processes ("Thinking Process") in toggleable containers.
- **Fluid Desktop UX**:
  - Damped, physics-based scroll tracking with user-scroll detection and a resume floating action button.
  - Multiline message composition with `Shift + Enter` or `Alt + Enter` (and `Enter` to submit).
  - Native desktop window configuration (`DesktopWindowConfig`) with initial launch bounds (1100 × 750), enforced minimum constraints (800 × 600), and window centering.
  - Contextual error banners with a one-click `"Settings"` Call-to-Action.
  - Conversation management: Clear conversation session and Export conversation to formatted Markdown with preview and clipboard copy.
- **Secure Storage & Persistence**:
  - Encrypted credential management via `SecureKeyStore` backed by `flutter_secure_storage` (macOS Keychain, iOS Keychain, Android Keystore, Windows Credential Manager, Linux libsecret).
  - Automatic migration of legacy plaintext API keys from `SharedPreferences` to secure encrypted storage.
  - Test-friendly `InMemoryKeyStore` for zero-dependency headless unit and widget testing.
  - Chat message history and active GenUI surface restoration across app restarts.

## Architecture Overview

```
lib/
├── main.dart                               # App entrypoint, window initialization, and theme setup
├── models/
│   ├── chat_message.dart                   # Chat message domain model with GenUI surface IDs & thoughts
│   └── process_log_entry.dart              # Subprocess trace event model with direction & timestamp
├── services/
│   ├── antigravity_service.dart            # Agent lifecycle, GenUI controller, session persistence, logging bridge
│   └── secure_key_store.dart               # Secure encrypted credential store (Keychain/Keystore) & migration
├── ui/
│   ├── chat_screen.dart                    # Main chat interface, bubble rendering, shortcuts, export & drawer
│   ├── genui/
│   │   ├── confirmation_card_item.dart     # GenUI CatalogItem for action/tool approvals & confirmations
│   │   ├── feedback_rating_card_item.dart  # GenUI CatalogItem for star ratings and user feedback
│   │   └── multiple_choice_question_item.dart # GenUI CatalogItem with "Other" write-in & multiselect
│   ├── process_log_panel.dart              # Real-time slide-out subprocess trace panel with YAML highlighting
│   └── settings_dialog.dart                # Model, API key, and system instructions configuration
└── utils/
    ├── desktop_window_config.dart          # Native desktop window sizing, centering, and min-constraints
    └── yaml_highlighter.dart               # JSON-to-YAML parser and syntax highlighter
```

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.x or higher)
- A Google Gemini API Key (obtainable from [Google AI Studio](https://aistudio.google.com/))

### Setting up the API Key

You can provide your Gemini API key in either of two ways:

1. **Environment Variable** (recommended for local development):
   ```bash
   export GEMINI_API_KEY="your-gemini-api-key"
   ```
2. **In-App Settings Dialog**:
   Launch the app, click the **Settings** icon (`Icons.tune`) in the AppBar or click **Settings** on the startup error banner, enter your key, and click **Save & Apply**. The key is securely encrypted in your platform's native keychain / credential store.

### Running the App

Run the desktop application on macOS (or your target desktop platform):

```bash
flutter run -d macos
```
